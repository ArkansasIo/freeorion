Browser-port status: The Browser Lab is a playable, simplified strategy prototype. It is not the original FreeOrion engine. Running the complete game requires porting the C++ engine and its GiGi/OpenGL, SDL2, audio, Python scripting, resource, save/load, and AI integrations to browser-compatible APIs.
FreeOrion is an open-source community project. Review the repository’s license and bundled third-party notices before redistributing source code, assets, or builds.
